# Turing Machine Simulator

Simulador interactivo de Máquinas de Turing desarrollado para la materia de Gramáticas y Lenguajes Formales utilizando React, Vite, Node.js y Express.

El proyecto permite crear y simular Máquinas de Turing mediante una interfaz visual, facilitando la comprensión de conceptos fundamentales de teoría de la computación y lenguajes formales.

---

## Descripción

El simulador permite:

- Definir estados y transiciones.
- Simular el funcionamiento de una Máquina de Turing.
- Visualizar el movimiento del cabezal sobre la cinta.
- Ejecutar simulaciones paso a paso o de manera automática.
- Analizar el procesamiento de cadenas y algoritmos computacionales.

## Instalación

### Clonar el repositorio

```bash
git clone https://github.com/USUARIO/TuringMachine-simulator.git
```

---

### Ejecutar el frontend

```bash
cd frontend
npm install
npm run dev
```

---

### Ejecutar el backend

```bash
cd backend
npm install
npm server.js
```
